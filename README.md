Files with Markdown
===================

A mod for Herdr App 0.1.13 and later: Herdr's Files panel with Markdown
rendered and images previewed in place, on this computer or a remote space.

- Click a `.md`, `.mdx` or `.markdown` file to read it formatted.
- Click an image to see it fitted to the panel.
- Right-click a Markdown file to open it in Markdown Browser's pane, when that
  mod is installed.
- Other files keep Herdr's read-only source preview.

Files with Markdown is a modified clone of the Files mod shipped with Herdr
App 0.1.13. See [RECIPE.md](RECIPE.md) for what it does, how to install it,
and what it runs. Herdr App is licensed under Apache-2.0; see [LICENSE](LICENSE)
and [NOTICE](NOTICE).

Install (short version): copy `mods/files-markdown/` to
`~/.config/herdr-app/mods/`, point the Files block of your layout at
`files-markdown`, then run `herdr-app check` on the folder. The full steps,
including the layout clone, are in [RECIPE.md](RECIPE.md).
